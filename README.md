# TableTop — Переворот

Рабочая версия «Переворот», восстановленная от версии **No-Double-Turn**.

## Render

- Root Directory: пусто
- Build Command: `npm install`
- Start Command: `npm start`

Структура репозитория:

```text
package.json
server.js
public/
  index.html
  app.js
  style.css
```

Важно: загружайте содержимое этой папки в корень GitHub-репозитория, а не сам ZIP как единственный файл.
